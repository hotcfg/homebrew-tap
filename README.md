# hotcfg Homebrew tap

Homebrew cask for the [hotcfg CLI](https://github.com/hotcfg/cli), the
command-line tool for [hotcfg.run](https://hotcfg.run).

    brew install --cask hotcfg/tap/hotcfg

Upgrade with `brew upgrade --cask hotcfg`.

The cask is updated automatically by each [release](https://github.com/hotcfg/cli/releases).
Don't edit it by hand. Report issues in [hotcfg/cli](https://github.com/hotcfg/cli/issues).
